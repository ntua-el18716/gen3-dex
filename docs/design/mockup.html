Gen 3 Companion · design mockup (real data)

Principles

Clean canvas, colour as information. Type colours mark Pokémon and moves; the game you pick becomes the accent (try the buttons above). Authentic GBA sprites, shown crisp. Numbers line up. Every section has variants: tap A / B.

2 · Pokémon page (scroll inside it)

Scroll inside it: the header shrinks and crops the big sprite as it fades, the name slides up into a centred title, and a thumbnail appears. Snaps open or closed if you let go halfway. Stats with real Lv 50/100 ranges, plus values computed with the game's own formulas.

3 · Moves tab (Emerald, level-up)

C = each move is a small card; its type colour is the block on the left, with the type icon. Tap a move to expand it.
